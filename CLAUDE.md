# Стальная Дуэль — заметки для ИИ-ассистента

3D-гонка на двоих (split-screen) на Three.js 0.160 + Rapier 0.21 (оба с CDN). Без сборки и npm: `index.html` открывается с диска.
Пользователь пишет по-русски; комментарии в коде, интерфейс и README — на русском.

## Как устроен код
- `js/**` — **обычные скрипты, не ES-модули** (иначе игра не откроется с диска). Все файлы делят одну глобальную область видимости. Порядок загрузки — массив `FILES` в `index.html`; новый файл добавлять туда после файлов, от которых он зависит.
- `THREE`, `RAPIER`, `RoomEnvironment`, `mergeGeometries` — глобалы, их выставляет модуль в `index.html`.
- В шапке каждого файла: описание, затем строки `// Определяет:` и `// Использует:` (какие глобалы задаёт и чьи берёт). Они **генерируются** — после добавления/переименования глобалов запусти `node tools/deps.js --headers`.
- Подробности механик (физика, трафик, разрушаемые объекты, время суток, производительность) — в `README.md` по разделам; читай только нужный раздел.

## Экономия токенов
- Где определено имя и кто его использует: `node tools/deps.js --who ИМЯ`. Зависимости файла: `node tools/deps.js js/race.js`. Это дешевле, чем искать grep-ом по всем файлам.
- Читай шапку файла (первые ~15 строк) прежде чем читать файл целиком; в больших файлах — только нужный раздел (`/* ==== */` и `/* ---------- */` — заголовки разделов).
- Город — по этапам: правка района → `blocks.js`, мостов/эстакады → `infra.js`, уличной мелочи → `streets.js` (раскладка) и `props.js` (3D). Порядок этапов — в `cityData()` и `buildCity()`.

## Подводные камни
- **Город детерминирован** (зерно в `cityPlanBase()`): каждый новый вызов `R()` в середине раскладки меняет весь город после этого места. Если правка не должна менять город — сравни `__game.fingerprint('city')` (`dataHash`, `worldHash`) до и после, на свежей загрузке страницы до заезда.
- Этапы города обмениваются данными через объект-контекст (`C` в раскладке, `K` в постройке): этап берёт нужное деструктуризацией в начале и отдаёт новое через `Object.assign` в конце.
- Материалы, общие для многих мешей, помечены `userData.shared` (не уничтожать). Анимированное в статичных группах — `userData.dynamic = true`, иначе `optimizeStatic()` заморозит матрицу.
- Число источников света меняется только при загрузке заезда (иначе перекомпиляция шейдеров посреди игры).
- Цель производительности — ≥ 100 FPS вдвоём на встроенной Radeon 680M. Счётчик: клавиша Ё или `?fps` в адресе.
- Смена качества графики перезагружает страницу (MSAA задаётся при создании WebGL-контекста).

## Проверка изменений
1. Сервер: `.claude/launch.json` (python http.server). Если порт занят другой сессией — заведи конфиг с другим портом.
2. В консоли страницы: `await __game.selfTest()` — строит все карты, гоняет машины 4 с, включает ночь; отчёт текстом, «ошибок нет» = ок.
3. Рефакторинг генерации карт — `__game.fingerprint('city')` до и после (см. выше).
4. Скриншот — только для визуальных правок. Быстрый старт заезда: `__game.startMatch('free')` (или `'race'`, `'solo'`).
5. `node tools/deps.js --check` — шапки файлов актуальны.
