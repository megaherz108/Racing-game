# Карта «Ситжес» — план

Новая карта: реальный город Ситжес (Каталония, Испания) от района Террамар на западе до марины Айгуадольс на востоке.
Цель — как можно ближе к реальности в рамках mid-poly: планировка улиц, форма и высота зданий, их вид, рельеф,
покрытие дорог, узнаваемые строения.

**Как пользоваться.** Сессия по карте начинается с чтения этого файла (не кода и не данных) и заканчивается его
обновлением: «Статус» (одна строка на сделанное), «Дальше», «Открыто». Подробности — в архиве `docs/sitges/`, читать
только нужный файл. Решения и замеры нового этапа пишутся в его файл архива, сюда — только итог в одну-две строки.
Этот файл держать коротким (≤ ~150 строк): его читают целиком каждую сессию.

## Как проверять

```
node tools/sitges/download.js     # сырые данные в tools/sitges/raw/ (в .gitignore); есть — не качает; --force — заново
                                  # плитки orto/, dsm/ — по data-geo.js: на новом компьютере build.js, потом download.js ещё раз
node tools/sitges/build.js        # raw → js/maps/sitges/data-*.js, сводка и сверка ориентиров (≈ 2 с)
node tools/sitges/roofs-sheet.js  # лист: типы крыш поверх ортофото в 6 местах → tools/sitges/raw/roofs-sheet.png
node tools/deps.js --check
node tools/cdp.js --inject tools/sitges/check.js --eval "await __sitgesCheck()"           # метрики карты
node tools/cdp.js --inject tools/sitges/check.js --eval "await __sitgesShots()" --dir shots  # снимки контрольных мест
node tools/cdp.js --inject tools/sitges/fence-debug.js --eval "await __fenceMap(['Vinyet 44'])" --dir shots   # схема заборов у адреса
node tools/cdp.js --inject tools/sitges/fence-debug.js --eval "await __fenceShots(['Vinyet 44'])" --dir shots # забор в 3D
node tools/cdp.js --eval "await __game.selfTest()"
```

- `tools/cdp.js` сам поднимает статический сервер на свободном порту и безголовый Edge (видеокарта настоящая, вкладка
  на переднем плане — время честное), выполняет выражение и закрывает браузер. Подробности — шапка файла.
- `__sitgesCheck()` — время постройки, сводки этапов, ширины, углы, щели у касаний углов, ровность полотна, крутые
  места; с `{ base }` — сравнение с прошлым результатом. Эталон — `tools/sitges/check-base.json`
  (`--save tools/sitges/check-base.json`). Что меряет — шапка `tools/sitges/check.js`.
- Дыра в заборе (адрес со скриншота): `__fenceMap(['улица номер'])` — схема сверху, куски линии забора цветом причины
  «забора нет» (легенда на картинке), итоговые заборы и их концы; `__sitgesFind([...])` — координаты дома по адресу;
  `__fenceShots` — кадр в 3D. Найти причину по схеме, исправить правило в `fences.js` для всего города, проверить
  группу `holes` в `__sitgesCheck()`. Причины прошлых дыр и правила — `stage-4a.md`, «Дыры в заборах».
- **Новый район или правка улиц, тротуаров, участков** — заборы (чек-лист): `__sitgesCheck()` с `--compare` — `fences.km`
  и `holes` (пары близких концов, дуги углов без забора) не должны резко вырасти; `__fenceMap` на 3–4 углах, у улицы
  без тротуара и у пешеходного переулка района; новые данные — те же ловушки: кольцо угла навстречу тротуару, участок
  в 4–12 м от тротуара, улица без тротуара, дороги внутри большого участка (порт, комплекс).
- `__game.fingerprint('sitges')` — до и после рефакторинга (раскладка по полям `C.*`, мир со столкновениями тротуаров).
- В игре: `__game.startMatch('free', 'sitges')` или «Ситжес» на экране режима; старт — набережная Passeig de la Ribera.

## Правила

- Сырые скачанные данные — вне репозитория (папка в `.gitignore`); в git — только готовые `data-*.js`
  и скрипты, которые их делают.
- Файлы `data-*.js` не читать и не искать по ним (см. CLAUDE.md); скрипты конвейера печатают сводки, а не данные.
- Случайность (`R()`) — только для мелочей (окна, оттенки); всё, что есть в данных, — из данных.
- Внешний вид (цвета, пропорции фасадов, ставни, балконы, заборы, мощение, мелочи улиц) не придумывать, а сверять
  с фото-образцами `tools/sitges/raw/photos/` (вне git): сначала сводка `docs/sitges/photos.md`, затем `index.md`
  района или `sv/index.md` (кадры Street View по типам домов: год, этажи, координаты игры), листы-обзоры —
  `python tools/sitges/sheets.py`, отдельный кадр — только если на листе неясно. Папки нет (другой компьютер) —
  `node tools/sitges/streetview.js` (ключ — у пользователя). Числа из фото (доли видов, этажи, цвета) — в файл этапа.
- Пользователь проверяет ездой и присылает скриншоты огрехов: исправлять по всему городу, а не в одном месте, и мерить
  итог глобальной метрикой (`__sitgesCheck()`), а не на глаз в точке со скриншота.
