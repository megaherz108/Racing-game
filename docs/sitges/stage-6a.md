# Этап 6а — вывески заведений (план, 2026-11-21)

Узнаваемые вывески ресторанов, баров, кафе, супермаркетов, аптек, банков, отелей и заправок по точкам OSM; на
безымянных витринах — типовые. Террасы (столики, зонтики, штендеры) — не здесь, а в этапе 7 (решение пользователя).

## Решения пользователя (2026-11-21)

1. **Бренды — цвета + название**: фирменные цвета сети и её название крупно нашим шрифтом; логотипы не перерисовываем
   (ни формы, ни значки).
2. **Охват**: все заведения OSM с названием + типовые вывески на витринах без названия.
3. **Ночью светятся** — свечение материала от `NIGHT_U` (как окна в `facade.js`), без источников света.
4. **Террасы — этап 7.**

## Виды вывесок

| Заведение | Вывеска | Где |
|---|---|---|
| ресторан, кафе | доска над витриной; на набережной и в старом городе — тент-маркиза с названием на фестоне | над витриной, 2,9–3,6 м |
| бар, клуб | доска + флажок (неон ночью) | флажок поперёк улицы — читается на скорости |
| аптека | зелёный крест на кронштейне (светится) + доска «Farmàcia» | крест на углу или у входа |
| супермаркет | широкий короб в цветах сети; отдельное здание (Lidl, ALDI, Mercadona) — ещё стела у въезда | над входом; стела — у края участка |
| банк | короб в цветах банка + флажок | над входом |
| заправка | навес в цветах бренда, стела | по контуру OSM / у точки |
| отель | крупные буквы наверху фасада или на крыше (по высоте дома) | фасад к морю или к самой широкой улице |
| типовая | «Bar», «Restaurant», «Forn», «Fruiteria», «Perruqueria», «Bodega», «Botiga»… | витрины кадастра (`W.shops`) без точки OSM рядом |

Типовые не бывают аптекой, банком, супермаркетом или отелем — эти места люди знают, ложные не ставим.

## Шаги

- **6а.0 — данные.** `build.js` → `data-venues.js`: точка (у контура — середина), вид, название (`name`, иначе
  `name:ca`), бренд из таблицы, признаки (терраса, кухня). Сводка по видам в выводе `build.js`.
- **6а.1 — раскладка `signs.js`** (после `styles.js`): точка → ближайший кусок фасада к улице (как `nearShop` в
  `houses.js`), проекция на стену, вид вывески по таблице, ширина по куску и длине текста, высота над витриной
  (`SITGES_FAC.shopY`), без наложения на балконы `C.balconies` и двери; части строений (`h.lm`) пропускать. Типовые —
  по хешу места и району (старый город и набережная — бары и рестораны, Эшампле — лавки), **без `R()`**. → `C.signs`.
  Отладка — схема у адреса (по образцу `__fenceMap`).
- **6а.2 — надписи `signtex.js`**: атлас canvas при загрузке (1–2 листа 2048², проверить видеопамять), текст ужимается
  по ширине (`measureText`), шрифты системные Windows с запасными; палитры — `SITGES_SIGN` (по видам) и `SITGES_BRANDS`
  (цвета — из открытых источников: свойство «официальный цвет» в Wikidata по `brand:wikidata` из OSM, страницы
  брендбуков; не по памяти). Кадры Street View в 6а.4 — не ради цвета, а ради вида конкретной вывески в Ситжесе: короб
  или буквы, светлый фон или цветной, высота, флажок. Вторая текстура или канал — маска свечения.
- **6а.3 — постройка `signs3d.js`**: доски-коробы, двусторонние флажки, маркизы, кресты, буквы отелей, стелы, навес АЗС;
  склейка квадратами 160 м со скрытием дальше ≈ 150 м (как заборы); один материал на квадрат; ночью —
  `emissive` от `NIGHT_U`. Тени не отбрасывают (кроме навеса АЗС); стелы — столб в сетке столкновений.
- **6а.4 — сверка по фото**: `streetview.js` — кадры у ≈ 20 главных мест (набережная, Mercadona, Lidl, ALDI, Calípolis,
  Meliá, Terramar, Prado, рынок) → поправить вид, цвета, высоту. Закрыть огрехи этапов 5–6: вывеска рынка, надпись Прадо.
- **6а.5 — цена кадра — не делаем** (решение пользователя 2026-11-21: если будет тормозить, заметит сам; замеры
  не тратить). Оценка: ≈ 500 вывесок, ≈ 6 тыс. треугольников.

## Сессии и договор между ними

Три сессии, каждая в своём worktree и своей ветке; сливает в `main` основная сессия.

- **A — 6а.0 + 6а.1** (данные и раскладка): `tools/sitges/build.js`, `js/maps/sitges/data-venues.js`, `signs.js`,
  порядок в `sitgesData()` (`plan.js`), `index.html` (FILES), отладка схемы. Итоги пишет в этот файл (разделы 6а.0, 6а.1).
- **Б — 6а.2** (параллельно с A): `js/maps/sitges/signtex.js`, витрина атласа `tools/sitges/signs-show.js`,
  `index.html` (FILES), источники цветов — `docs/sitges/sign-colors.md`. Этот файл не правит.
- **В — 6а.3 + 6а.4** после слияния A и Б: `signs3d.js`, вызов из `build.js` карты, сверка по фото, огрехи рынка и Прадо.
- `docs/sitges-plan.md` правит только основная сессия.

**Ключи брендов** (A сопоставляет `brand` и `name` OSM → ключ, Б рисует по ключу): `mercadona`, `caprabo`, `lidl`,
`aldi`, `dia`, `bonpreu`, `consum`, `carrefour`, `supercor`, `caixabank`, `bbva`, `sabadell`, `santander`, `repsol`,
`q8`, `365`, `clarel`, `womensecret`; нет бренда — `null`.

**Виды заведений** (`cat`): `restaurant`, `cafe`, `bar`, `club`, `fastfood`, `icecream`, `bakery`, `supermarket`,
`convenience`, `pharmacy`, `bank`, `fuel`, `hotel`, `shop` (прочие магазины). **Формы** (`form`): `board` (доска-короб),
`blade` (флажок, двусторонний), `awning` (маркиза, надпись на фестоне), `cross` (аптечный крест — без текста),
`letters` (буквы отеля), `totem` (стела), `canopy` (навес АЗС, надпись по кромке).

**`C.signs`** (раскладка, A) — массив `{ x, y, z, nx, nz, w, h, form, cat, text, brand, generic, key }`: середина лица
вывески (y — от уровня моря, как дома), наружная нормаль стены в плоскости xz, ширина и высота лица в м, `generic` —
типовая, `key` — строка `form|cat|brand|text` для атласа (одинаковые вывески делят ячейку). Флажок и крест — `x, z`
у стены, торчат по нормали; размер `w × h` — лицо.

**Атлас** (Б) — `sitgesSignAtlas(items)`, `items` — уникальные `{ key, text, cat, brand, form, aspect }` (`aspect` =
w / h из раскладки); возвращает `{ map, glow, uv: Map(key → [u0, v0, u1, v1]) }`: `map` — цвет (sRGB), `glow` — маска
свечения (что светится ночью: буквы, крест, неон); текст ужимается под `aspect`. Палитры — `SITGES_SIGN` (по `cat`),
`SITGES_BRANDS` (по ключу).
