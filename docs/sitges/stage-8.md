# Этап 8 — трафик «Ситжеса»

План составлен 2026-11-23 (обсуждение с пользователем). Статус и следующий шаг — в `docs/sitges-plan.md`.

## Решения пользователя

- Трафика **немного** — город не должен быть забит машинами.
- Легковые — **все 10 машин игроков** (Corolla, Golf, Нива, Accord, Mustang, X5, WRX, Hummer, 911, Aventador),
  **разных цветов** — все 12 цветов гаража (`CARS`-цвета в `data.js`: белый, жёлтый, фиолетовый, розовый,
  оранжевый, голубой, синий, серый, красный, лаймовый, зелёный, чёрный).
- **Такси** тоже есть, по всему городу (как легковые).
- **Автобусы и грузовики** — только на широких дорогах.
- **Припаркованных машин нет** — отложено на будущее (пункт в «Открыто» плана).

Предложено и не оспорено (подстроить по езде пользователя):
- машины держатся **вокруг игроков** (как в «Городе»), а не на всю карту (как на «Побережье»): на 71 км проезжих
  улиц 20 машин на всю карту — одна на 3,5 км, их бы почти не видели;
- число — по настройке «Мало / Средне / Много»: ≈ **6 / 12 / 20** вокруг каждого игрока (у «Города» 40 / 90 / 180);
- доли: обычные (Corolla, Golf, Accord, X5, Нива) и такси — чаще; Mustang, WRX — реже; Hummer, 911, Aventador —
  редко; автобусы и грузовики — немного;
- трафик во **всех режимах** «Ситжеса»; подсказку «на Ситжесе трафика пока нет» (`js/ui.js`) убрать.

## Что взять у других карт

Код трафика общий (`js/traffic/`): объект `Traffic`, водитель `driver.js`, модели `models.js`, проверка `test.js`.
Карта отдаёт граф и настройки (`world.traffic`).

- **«Побережье»** (`js/maps/coast/trafficnet.js`) — образец графа: ребро — направленная полоса-ломаная `lp` с касательными
  `ix/ex`, высотой полотна `hy` (мосты, путепроводы) и скоростью `vprof` по радиусу поворота; главная / второстепенная
  (`major`, `giveWay`), кольца (`round`, `roundYield`), узкие участки по очереди (`narrow`), запреты по ширине и длине
  (`maxW`, `noLong` у ребра, `type.long` у машины — `driver.js`, `fits`), объезд предметов сдвигом оси, сводка по связности.
- **«Город»** (`js/traffic/graph.js`) — граф на прямой сетке (оси `x`/`z`), для кривых улиц не годится. Берём:
  появление вокруг игроков (не `global`), число по `TRAFFIC_LEVELS`, светофоры `trafficLight`, правило «кто долго
  ждёт — пропустим» (`blocked`), модели такси, автобуса, грузовика (`buildTaxiModel`, `buildBusModel`, `buildTruckModel`).
- Звук моторов уже есть: `audio-traffic.js` берёт профиль `ENGINE[id]` машины игрока.

## Граф — `js/maps/sitges/trafficnet.js`

Строится при первом заезде с трафиком из готовой раскладки, раскладку не меняет (`dataHash` прежний).

- **Улицы** — `C.streets` по оси после сдвига (`shift`), ширина проезжей части `hw`, классы `SITGES_R.cls`.
  Без трафика: пешеходные, `living_street` (плитка), ж/д и треки, улицы уже ≈ 5 м (≈ 9 % проезжих).
- **Узлы** — перекрёстки как у скруглённых углов (`corners.js`: вершина OSM с ≥ 3 рукавами, стык разных улиц,
  конец улицы на середине другой). Начало и конец полосы — у края перекрёстка (дуги угла `C.corners`).
- **Полосы.** Односторонка (`oneway` 1 / −1, кольца) — одна полоса посередине; двусторонняя — по одной в каждую
  сторону, справа от оси на ¼ ширины. `lanes` из OSM пока не используем (почти везде по одной).
- **Высота** — полотно `sitgesEvenRoads()` / мосты / путепроводы `C.unders` (подъезды до ≈ 23 %, см. «Открыто», «Полотно»).
- **Скорость** — городская, ≈ 30 км/ч (≈ 8,5 м/с; на асфальте «30» этапа 7B), в старом городе и на узких — ниже,
  на поворотах — по радиусу (`vprof`).
- **Тупики** — без трафика. **Связность**: с односторонками бывают «ловушки» (въехать можно, выехать нельзя) —
  оставить только самую большую сильно связную часть графа; сводка: сколько км отброшено и где.
- **Кольца** — 10 центров колец этапа 7G (`junction=roundabout`); кольцо из нескольких кусков OSM (у (91, 296))
  сейчас не распознаётся — починить здесь (заодно огрех углов 3а).
- **Широкие дороги** (автобусы, грузовики): двусторонние улицы классов `secondary` / `tertiary` с проезжей частью
  ≳ 7 м и без тесных поворотов; остальные рёбра — `noLong`. Подграф широких дорог тоже должен быть сильно
  связным (иначе длинная машина застрянет у края) — длинные появляются только на нём. Порог подобрать по сводке
  (сколько км выходит) и по схеме сверху.
- **Предметы на проезжей части** (столбики, «столы», террасы у бордюра) — проверить, что полосы их не задевают;
  задевают — объезд сдвигом оси, как на «Побережье».

## Кто уступает

- **Главная** — по классу улицы (secondary > tertiary > unclassified > residential), при равном — сквозная.
- **Знаки этапа 7B**: въезд со STOP или «уступи» (знак или треугольник на асфальте) — второстепенный, даже если
  класс выше.
- **Светофоры** — только 2 из OSM (Santiago Rusiñol, Plaça de l'Hospital). Фазы — по группам рукавов (пары
  встречных); водителю нужна правка: вместо осей `x`/`z` у ребра — номер группы (`trafficLight` с группой 0/1).
  Визуал светофоров 7B переключать той же фазой.
- Кольца — `roundYield`; узкие участки на двусторонних улицах (если найдутся) — `narrow` по очереди.

## Машины

- `world.traffic = { types: SITGES_TRAFFIC_TYPES, count: { low, mid, high } }`, без `global`.
- Типы — 10 машин игроков (модели `buildCarModel`, «запекаются» как у «Города»), цвета — 12 цветов гаража;
  такси — модель «Города» (окраску сверить с фото-образцами); автобус и грузовик — модели «Города», `long: true`.
- Hummer (широкий) — не на самые узкие улицы (`maxW` у ребра), как трактор на «Побережье».
- Кольцо появления — подобрать: в «Городе» 170–380 м, а в «Ситжесе» дома закрывают вид — возможно, ближе
  (своё значение у карты, если общее не подходит).
