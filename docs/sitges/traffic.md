# Трафик «Ситжеса» — как устроен и как чинить

Справочник для агентов, которые чинят трафик «Ситжеса» по жалобе пользователя. Этап 8 закрыт 2026-11-24
(пользователь проверил ездой: всё нормально). История решений, цифры и замеры шагов 8.0–8.2 — в `stage-8.md`
(читать только нужный раздел «Итоги 8.x»); общие правила трафика всех карт — в `README.md`, «Трафик».

## Что где

| Что | Где |
|---|---|
| Граф: улицы, узлы, полосы, высоты, скорости, кольца, знаки, светофоры, запреты, повороты `e.turns` | `js/maps/sitges/trafficnet.js` — `sitgesTrafficGraph()`, настройки `SITGES_NET` (каждое поле с комментарием) |
| Подключение к миру, число машин, кольцо появления | `js/maps/sitges/build.js` — `trafficGraph`, `SITGES_TRAFFIC` (`count`, `ring`) |
| Типы машин, доли, цвета, скорость | `js/traffic/models.js` — `SITGES_TRAFFIC_TYPES` (10 машин игроков, такси, автобус и грузовик с `long`) |
| Появление и исчезновение, «не на виду», удары, отрисовка | `js/traffic/traffic.js` — `Traffic`, `TRAFFIC_RING`, `Traffic.seen()` |
| Вождение: кто уступает, светофоры, STOP, дистанция, застревание | `js/traffic/driver.js` — общий для всех карт |
| Фаза светофора (машины и лампы 7B) | `js/maps/sitges/st/marks.js` — `stMarkSignal(grp, t)` |
| Проверка поведения | `js/traffic/test.js` — `trafficTest({ map: 'sitges' })` |
| Схема графа сверху и сводка | `tools/sitges/traffic-debug.js` — `__netMap()`, `__netInfo()`, `__netGraph()` |

Путь данных: раскладка (`C.streets`, `C.corners`, точки OSM 7B, кольца 7G) → при первом заезде `world.trafficGraph()`
строит граф (≈ 0,25 с, кэш `world.__trafficGraph`) → `Traffic.start` → водитель ведёт машины по `e.lp[0]` и `e.turns`.
Граф раскладку не меняет: `dataHash` после любой правки графа или водителя должен остаться прежним.

## Решения пользователя (не менять без него)

- Трафика немного: 6 / 12 / 20 машин вокруг каждого игрока («Мало / Средне / Много»).
- Легковые — все 10 машин игроков во всех 12 цветах гаража; такси по всему городу; автобусы и грузовики — только на
  широких дорогах (`SITGES_NET.wide`).
- Трафик во всех режимах «Ситжеса».
- Отложено: припаркованные машины; разворот в тупике (Passeig de la Ribera западнее (−160, −62) без трафика: её конец
  упирается в пешеходную зону).

## Симптом → где искать

| Жалоба | Вероятная причина | Где править |
|---|---|---|
| На улице нет машин | улица отброшена: узкая (< `minW`), тупик, петля, «ловушка» односторонок, класс не из `prio` | `__netMap` — отброшенное окрашено цветом причины; `G.dropped`, `G.report` |
| Машина едет против односторонки / не туда | `oneway` из OSM (1 / −1), склейка улиц | `trafficnet.js` (полосы), данные — `tools/sitges/read-osm.js` |
| Машина кружит, дёргается в повороте, задевает дом или бордюр | кривая поворота `e.turns` (квадратичная / кубическая / разворот) | `SITGES_NET.turn`; на схеме — место, в `trafficTest` — «стояние» и «авария» с координатами |
| Пробка у перекрёстка, обе ждут друг друга | главная / второстепенная, стоп-линия близко к чужому въезду (`stopGap`), узел пересечения без общей вершины OSM (`G.report.crossings`) | `trafficnet.js` (узлы, `major`, `stopGap`), `driver.js` (`blocked`, `giveWay`, `oncoming`, `exitBlocked`) |
| На кольце пробка или авария | узел `round`, радиус полосы, `roundYield` | `SITGES_NET.ring`, `driver.js` |
| Проезд на красный | короткая полоса до светофора, решение «ехать на жёлтый» | `driver.js` (`TRAFFIC_SIG_SHORT`), фаза — `stMarkSignal` |
| Машина висит в воздухе / проваливается | высота полосы `hy` (мосты, путепроводы, спуски под ж/д) | `__netInfo()` → `hy` (точки > 0,5 м); `trafficnet.js` |
| Машина упирается в невидимую стену или в мост | перила или настил над полосой (`clearDeck`, `deckLow`), дом над проездом (`clearCar`, `clearLong`) | `trafficnet.js`; коллайдер перил — `js/maps/sitges/roads3d.js` (`parapet`) |
| Машина застряла о столбик, «стол» перехода, террасу | предмет этапа 7 на проезжей части; объезд сдвигом оси (`shift`) | `trafficnet.js`; на схеме — красный крест; упёршийся бот сбивает сбиваемое через 1,5 с, переставляется через 45 с (`pushT`) |
| Автобус в тесном повороте задевает соседнюю полосу | длинным нужен свой разбор поворотов (открыто) | `SITGES_NET.turn.longW/longL`, `wide.minR` |
| Машины появляются / исчезают на глазах | кольцо появления, проверка «на виду» | `SITGES_TRAFFIC.ring` (`min`, `max`, `drop`, `over`, `hide`), `Traffic.seen()` |
| Слишком много / мало машин, не те доли | число и веса | `SITGES_TRAFFIC.count`, веса `w` в `SITGES_TRAFFIC_TYPES` — после согласия пользователя |

## Как проверять

```
node tools/cdp.js --inject tools/sitges/traffic-debug.js --eval "await __netInfo()"                     # сводка графа
node tools/cdp.js --inject tools/sitges/traffic-debug.js --eval "await __netMap([['place', x, z, 70]])" --dir shots   # схема места
node tools/cdp.js --eval "await __game.trafficTest({ map: 'sitges' })"                                   # ≈ 3 мин, все сценарии
node tools/cdp.js --eval "await __game.trafficTest({ map: 'sitges', scen: ['rings'], seconds: 60 })"     # один сценарий
node tools/cdp.js --eval "await __game.trafficTest()"                   # «Побережье» — после правки driver.js / traffic.js
node tools/cdp.js --eval "await __game.trafficTest({ map: 'city' })"    # «Город» — то же
node tools/cdp.js --eval "await __game.selfTest()"
```

- Сценарии «Ситжеса» (`scen`): `old`, `unders`, `rings`, `wide`, `junction`, `soak` — что каждый делает, в шапке
  `js/traffic/test.js`. Отчёт даёт координаты худших мест: открывай их схемой `__netMap`.
- Ориентир (после 8.2): аварий без игроков 0–1 за полный прогон, застрявших насовсем 0–1, на красный 0, самое долгое
  ожидание у перекрёстка 15–25 с. Прогоны шумят — сравнивай 2–3 прогона до и после, а не один.
- Правка водителя (`driver.js`, `traffic.js`) общая для всех карт: «Город» и «Побережье» не должны стать хуже.
- Правка графа — `__game.fingerprint('sitges')`: `dataHash` прежний; правка коллайдеров мира меняет `worldHash`
  и, возможно, `roadTris` в `__sitgesCheck()` — объяснить в итогах.
- Кадр (FPS) не мерить без просьбы пользователя.
- Итог правки — строка в `history.md`; новый огрех или отложенное — в «Открыто» `docs/sitges-plan.md`.
