# Этап 7 — мелочи улиц, набережная и пляж (план, 2026-11-21)

Всё, что делает улицу живой: фонари, разметка и знаки, уличная мебель, набережная, пляж, террасы заведений, склоны
и площади. Состав сверен с кадрами Street View (`sv/paving`, `sv/slope`, `sv/oldtown`, `sv/seafront`, `sv/y1940`),
фото районов (`photos.md`) и точками OSM (`raw/points.json`). Часть плана [docs/sitges-plan.md](../sitges-plan.md).

## Решения пользователя

- 2026-11-18 (решение 6): **не делаем** деревянные столбы с проводами, зеркала на углах, разметку парковок.
- 2026-11-21:
  - **Припаркованные машины** — не в этапе 7 (возможно, этап 8).
  - **Жёлтая линия у бордюра** (запрет стоянки, на кадрах склонов) — не делаем.
  - **Пляжные мелочи** (лежаки, зонты, пляжные бары, вышки спасателей) — обязательно.
  - **Мусорки** (контейнеры и урны) — не делаем; точки `amenity=recycling`, `waste_disposal`, `waste_basket` (58) не берём.
  - Реализация — отдельными сессиями по группам; эта сессия-оркестратор только планирует, сливает ветки и проверяет.
- Предложено и принято вместе с составом (2026-11-21):
  - светофоры — только по OSM (их 2), не на каждом углу, как в «Городе»;
  - знаки — только у точек STOP / «уступи дорогу» OSM и на въездах в односторонки, без «леса знаков»;
  - гидранты «Города» (с фонтаном при поломке) не переносить — на испанских тротуарах их почти нет;
  - столбики — только по точкам OSM и на краях пешеходных улиц старого города, сбиваемые; не вдоль всех тротуаров;
  - в старом городе — фонари на кронштейнах на стенах, не столбы;
  - кондиционеры и спутниковые тарелки на фасадах — не делаем (шум);
  - лодки уже есть в марине (`lm/marina.js`); на пляже — только если найдутся на фото;
  - бассейны вилл — плоской водой без геометрии, в конце.
- Уже сделано раньше, не повторять: плитка «панот» с гранитной кромкой, «зебры», ось улиц, велодорожки (этап 2), лодки
  марины (5–6), деревья в лунках (4б).

## Каркас (7.0, сделан 2026-11-21)

Как в этапах 5–6: общий каркас первым, затем группы параллельно, каждая — только в своих файлах. Подписи — в шапках
`street.js` и `street3d.js` (там полнее); здесь — что нужно группе, чтобы начать.

**Порядок.** Раскладка: `sitgesData()` → … → `sitgesPlanDoors` → **`sitgesPlanStreet`** (`street.js`) → мини-карта.
Постройка: `buildSitges()` → … → `sitgesBuildTrees` → **`sitgesBuildStreet`** (`street3d.js`) → склейка статики и теневые
копии (`sitgesBuildWorld`). Группы — объекты `SITGES_ST_A` … `SITGES_ST_G` в файлах `st/lamps.js` (A), `st/marks.js` (B),
`st/furniture.js` (C), `st/promenade.js` (D), `st/beach.js` (E), `st/terraces.js` (F), `st/slopes.js` (G); все семь уже
в `index.html` (перед `street.js`) и в списке `SITGES_ST_GROUPS` — порядок A → G и в раскладке, и в постройке.
Свои глобальные имена группы — с префиксом из шапки её файла (`stLamp…`, `stMark…`, `stFurn…`, `stProm…`, `stBeach…`,
`stTerr…`, `stSlope…`).

**Объект группы** `{ id, name, ready, plan(C, S), build(K, S, L) }`. Пока `ready: false`, ни plan, ни build не
вызываются — карта та же. `plan` возвращает данные группы (только данные: они хешируются отпечатком) →
`C.street.groups.<буква>`; `build` получает их третьим аргументом `L`.

**Раскладка — `C.street` (= S в plan).** Линии мест (данные, координаты игры; у отрезка `ax, az, bx, bz, nx, nz, len`):

| Список | Что | Нормаль | Ещё поля |
|---|---|---|---|
| `curbs` | бордюр полос тротуара (`C.walks`), 21 914 | от бордюра к дому | `w0, w1` — ширина тротуара на концах, `si` — улица (индекс `C.streets`), `side`, `wi` — индекс `C.walks` |
| `corners` | бордюр тротуаров скруглённых углов, 8549 | к дому | как у `curbs`, `wi = −1 − индекс угла` |
| `fronts` | наружный край полос (линия забора / фасадов) | к улице | как у `curbs` |
| `edges` | край полотна улиц без тротуара (проезжие и пешеходные, не мосты), 8421 | наружу | `si, i` (отрезок оси), `side` |
| `walls` | стены домов к улице (вид street / shops, не строения), 4786 | наружу | `ga, gb` — земля у концов, `lo, hi` — низ и верх стены, `h` — индекс `C.houses`, `kind` |
| `zebras` | «зебры» у концов улиц (их рисует `roads3d.js` по этому списку), 540 | — | `si, x0, z0, zx, zz, hw, len, sw` |

Помощники (функции S; место `spot` = `{ x, z, tx, tz, nx, nz, ry, f, w, seg, s, L }`, `ry` — поворот, при котором +z
модели смотрит по нормали, `w` — ширина тротуара в точке):

- `S.at(seg, f, off)` — точка на доле `f` отрезка со сдвигом `off` м по нормали.
- `S.along(segs, step, fn, { start = step/2, end = 0.5, retry = 1, off = 0 })` — вдоль цепочек (отрезок начинается там, где
  кончился предыдущий) с шагом `step`; `fn(spot)` → `true` — поставлено, дальше шаг; иначе дальше `retry` м; `off` — число
  или `(seg, f) → м` (середина тротуара: `(s, f) => (s.w0 + (s.w1 - s.w0) * f) / 2`). Возвращает число поставленных.
- `S.reserve(x, z, r, who, x2, z2)` — занять круг или капсулу (отрезок с радиусом); `who` — буква группы.
  `S.free(x, z, r, skip, x2, z2)` — свободно ли; `S.hits(…)` — что мешает; `skip` — who, которых не считать (строка,
  список, функция).
- `S.nearest(list, x, z, maxD)` — ближайший отрезок списка `'curbs' | 'corners' | 'fronts' | 'edges' | 'walls'` →
  `{ seg, d, f }`; `S.onWalk(x, z)` — точка на полосе тротуара → `{ seg, f, d (от бордюра), w }`.
- `S.carriage(x, z)` (= `C.carriageAt`), `S.oldTown(x, z)` (круги `SITGES_OLDTOWN`), `S.hash(x, z, k)` — 0…1 по месту
  (вместо `R()`: раскладка остального города не меняется).
- Каркас 7.1 (из групп A, B, C; неперечисляемые — отпечаток `C.street` от них не зависит):
  - `S.axis(st, s)` — точка оси улицы `st` (`C.streets`) на длине `s` м → `{ x, z, tx, tz, hw, sw, i, t, deck }`: касательная,
    полуширина полотна, `sw` — меньшая из ширин тротуаров концов отрезка, отрезок оси `i` и доля `t`, `deck` — на мосту
    (`v[i].deck`). `S.project(st, x, z)` — обратно: длина `s` ближайшей точки оси.
  - `S.near(x, z, ax, az, r, half = 0, d = 0.6, n = 3)` — ближайшее свободное место: сдвиги вдоль `(ax, az)` на 0, ±d … ±n·d,
    капсула ±half вдоль оси радиусом r → `[x, z]` или `null`.
  - `S.wallFit(x, z, nx, nz, y, { up, down, r, gap })` — высота вещи на стене к улице (точка на стене, нормаль наружу, желаемая
    высота): вещь от `y − down` до `y + up` задевает плиту балкона (`C.balconies`) ближе `r` м вдоль стены — опускается под
    плиту; вывеска той же стены (`C.signs`, кроме стел) ближе `gap` м — `null`. По умолчанию — кронштейн фонаря A
    (0,1 / 0,8 / 0,35 / 0,6); для широкого (тент F) — `r` и `gap` на полуширину больше.
- Каркас 7.2 (из групп D, F; тоже неперечисляемые):
  - `S.probe(x, z, nx, nz, g0, o)` — луч от стены по нормали «до чего свободно» → `{ U, why, ped }`: `U` — последняя
    свободная точка, `why` — `house` (дом), `road` (проезжая часть, угол; пешеходная улица — не конец, `ped = true`),
    `fence` (забор), `drop` (перепад больше `drop` от `g0` или вода), `open` (до `max`); `o` — `{ step, max, start, drop,
    sea }` вместо `SITGES_ST.probe` (0,25 / 8 / 0,3 / 0,6 / 0,2).
  - `S.fenceCut(x0, z0, x1, z1)` — отрезок пересекает забор `C.fences`; `S.coastD(x, z, R)` — до линии берега `C.coast`, ≤ R.
  - `skip` в `S.hits` / `S.free` может быть функцией `(who, o)` — с самим элементом занятости: исключения по месту
    (кронштейн высоко на стене, своя дверь, переход у стены — так у F); зовётся только для пересекающих.
  - Стена «ломаная + низ / верх + нормаль» — `{ pts: [[x, z, nx, nz, низ, верх]], a: [длина до точки] }`, нормаль — к верхней
    стороне. Глобальные функции (рельеф у стены правят до улиц, из `sitgesPlanTerrain`, когда `C.street` ещё нет):
    `sitgesStWallLen(pts)` → `a`; `sitgesStWallAt(w, a)` — точка на длине → `{ x, z, nx, nz, foot, top, i, t }`;
    `sitgesStWallNear(T, walls, R, ext)` — ближайший отрезок стены у узлов сетки рельефа `C.terra` → Map узел →
    `{ d, s, foot, top, inside }`; `sitgesStWallGround(T, near, { band, flat, raise, lowFoot, rest })` — ложбина у стены
    (узлы ближе `band` — на низ: сетка 2,5 м не держит отвесную ступень, ложбину накрывает настил группы на верху стены
    с `S.collider` / `S.walk`) и подъём за стеной (до `flat` — не ниже верха, до `raise` — плавно); `lowFoot`, `rest` —
    свои правила нижней стороны (у D — профиль пляжа).

Занято каркасом до групп (`C.street.occ`, `who`): `gate` — калитки и ворота (полоса вдоль проёма с улицы, 2011), `car` —
съезд ворот поперёк тротуара (767), `door` — полоса перед дверью (638), `tree` — уличные стволы (2797), `zebra` (540),
`cross` — переходы OSM поперёк улицы (426), `sign` — стелы и навесы вывесок (19), `corner` — бордюр дуг углов (8549).
Радиусы — `SITGES_ST`. Раскладка каркаса — 46 мс.

**Постройка — `K.st` (= S в build).** Модель — в своих координатах (основание в y = 0, «лицо» к +z):

- `S.y(x, z, yMax)` — высота поверхности: рельеф, верх тротуара (`walkAt`), настил моста не выше `yMax`.
- `S.mat(hex, o)` — общий `MeshStandardMaterial` (кэш); `S.glow(day, night)` — «лампа»: `MeshBasicMaterial`, цвет `day`
  днём, `night` вечером и ночью.
- `S.place(parts, items, o)` — экземпляры по квадратам 160 м, квадрат скрыт дальше `o.far` (300 м) от камеры (список
  `K.roadLod`). `parts` — `[{ geo, mat, shadow, per, loc }]`; `items` — `[{ x, z, y, ry, s, rx, rz, color }]`.
  `o.brk` (параметры `Breakables`) + `o.hit = { r, h }` — сбиваемые: в сетке кругом, `it.brk` у предмета, тень сами
  (группа `userData.dynamic`), в `world.breakables`. Без `o.brk` — неподвижные: `o.hit` (круг) или `o.box = { w, d, h }`
  (повёрнутый ящик) в сетке, тень — теневыми копиями.
- `S.lights(list, o)` — ночные огни без источников света: ореол (`Sky.mats.halo`) и пятно на земле (`Sky.mats.pool`);
  `list` — `[{ x, y, z, gx, gz, r, it }]`, у сбитого `it` гаснут; `o` — `{ color, size, pool, poolColor, far }`.
- `S.circle(x, z, r, h)`, `S.box(x, z, w, d, rot, h)` — неподвижное в сетке столкновений.
- 7.1, «неровность» (лежачий «стол» B, стена и лестницы D, площадки G): `S.collider(v, i)` — своя сетка столкновений из
  треугольников (`v` — x, y, z подряд, `i` — индексы) → `world.meshColliders`; `S.walk(pts, ys)` — поверхность
  `[[x, z] × 4]` с высотой (число) или высотами углов → `walkAt` (`S.y`, покрытие). Рисует меш сама группа.
- 7.2: `S.hash(x, z, k)` — то же, что в раскладке (`sitgesStHash`). `S.mesh(key, mat, o)` — своя геометрия, склеенная
  по квадратам (стены, настил, разметка, тенты): копилка на ключ, `o` — `{ shadow = true, chunk = 160, far = 300, index =
  true, uv = true, color = false, keep = false }`; писатель — `face(vs, n, uv, col)` (веер с заданной нормалью),
  `poly(vs, uv, hint, col)` (нормаль по трём вершинам, обход к `hint`), `beam(a, b, h, hw, uA, uB, col)` (брус вдоль
  отрезка); квадрат — по середине грани, `at(x, z)` — всё в квадрат точки. `S.flush()` — копилки → меши (сводка группы,
  `K.roadLod`); сам после `build`, но звать явно там, где меши должны встать в группе (до экземпляров — порядок влияет
  на склейку статики). `S.count(n)` — штук в сводку (что строится не через `place`).
- Сводка — `world.stats.street[буква]`: `{ n, tris, meshes, brk, lights }` (`__stInfo()`).

## Правила для сессий групп

1. Свои файлы — `js/maps/sitges/st/<группа>.js` и архив `docs/sitges/st-<группа>.md`. Общие файлы (`street.js`,

   предложить в каркас. Исключения: D и G — рельеф (`terrain.js`, `ground.js`) в своей полосе; F — тенты
   в `signs3d.js`. Новые глобальные имена — с префиксом группы, после — `node tools/deps.js --headers`.
2. Место — из данных (точки OSM, улицы, тротуары, участки), вид — по фото, не придумывать. Числа с фото — в свой архив.
3. Mid-poly: мелочь — десятки–сотни треугольников, инстансы, без новых источников света и своих шейдеров.
   Цену кадра не мерить (решение пользователя), в отчёте — штук, треугольников, вызовов отрисовки (`__stInfo()`).
4. Мелкое (скамейки, столбики, знаки, фонари, лежаки, зонты, мебель террас) — сбиваемое;
   стены, лестницы, ограда променада — неподвижные.
